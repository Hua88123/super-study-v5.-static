# 超能游学报价系统 V10.5 淡季优惠可手动选择版

## 本次修复

修复你说的问题：

后台设置好淡季优惠后，自动报价页面的“淡季优惠”勾选框点不了，点了也会自动变回去。

## 新增后台选项

后台位置：

学校数据库 → 学校设置 → 该学校默认启用的优惠

新增：

淡季优惠前端可手动选择

## 使用逻辑

### 关闭时

系统和以前一样：

自动报价页面会按照后台默认规则自动勾选/取消淡季优惠。

适合所有学生都统一享受优惠的学校。

### 开启时

自动报价页面的“淡季优惠”可以手动勾选或取消。

适合这种情况：

- 有些学生符合淡季优惠
- 有些学生不符合淡季优惠
- 需要顾问根据学生情况手动决定

## 默认优惠仍然保留

后台的：

默认启用淡季优惠

仍然有效。

例如你后台设置：

默认启用淡季优惠：启用  
淡季优惠前端可手动选择：启用

那么选择这个学校时，前端默认会先勾选淡季优惠。

如果这个学生不符合优惠，你可以手动取消。

如果学生符合优惠，就保持勾选。
