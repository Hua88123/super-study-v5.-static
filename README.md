# 超能游学报价系统 V10.2 多课程宿舍周数下拉修正版

## 本次修复

修复：

课程2周数、宿舍2周数不好选择的问题。

现在已经把周数从输入框改成下拉选择：

- 0周
- 1周
- 2周
- ...
- 24周

手机端也可以直接点开选择。

## 使用方式

自动报价页面：

多课程/多宿舍 → 开启

然后可以选择：

- 课程1周数
- 课程2
- 课程2周数
- 住宿1周数
- 宿舍2
- 宿舍2周数

## 防漏算规则保留

如果总周数是8周：

只选择课程2：4周  
课程1会自动补成4周

只选择宿舍2：4周  
宿舍1会自动补成4周

避免漏算费用。
