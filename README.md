# 超能游学报价系统 V12 手机端保存最终修正版

## 本次说明

你确认报价图模板可以，所以本版：

- 不改报价图模板
- 不改报价图规格
- 只修手机端保存失败

## 核心修复

新增 Vercel API：

/api/image-page

手机端不再直接下载 blob / dataURL，而是把生成好的报价图提交到一个真实的网页保存页。

这样手机端流程变成：

1. 点击“下载报价单图片”
2. 点击“手机保存页”
3. 进入独立保存页
4. 长按报价图保存到相册
5. 保存后点浏览器返回

这个方式比之前的 blob 下载、dataURL 新窗口、全屏模式更稳定。

## 为什么之前会失败

很多手机浏览器，特别是微信内置浏览器、iPhone Safari、部分安卓浏览器，对下面这些方式支持不稳定：

- blob 下载
- dataURL 下载
- a 标签 download
- 弹窗打开图片
- 长按 blob 图片

所以这版改成“真实网页图片保存页”。

## 部署

上传覆盖 GitHub 后，Vercel 重新 Redeploy。

注意：这版新增了 api/image-page.js，所以一定要上传整个 zip 里的 api 文件夹。
