# 超能游学报价系统 V11.7 手机端下载修正版

## 本次修复目标

保持你现在认可的报价图模板 **完全不动**，只修复：

- 手机端点击“下载报价单图片”失败
- 手机浏览器不支持直接下载 blob 图片
- 手机端无法顺利保存到相册

## 修复内容

1. **不改报价图样式和模板**
   - 这版不改报价图片排版
   - 只修手机端保存逻辑

2. **手机端改为更稳定的保存方式**
   - 支持“保存到手机 / 分享”
   - 如果浏览器不支持，就自动使用“打开图片后长按保存”
   - 兼容 iPhone / Android 常见浏览器

3. **电脑端逻辑保留**
   - 电脑端依然可以直接下载图片

## 使用方式

直接把这版文件覆盖到 GitHub / Vercel 项目后重新部署即可。

## 手机端使用说明

点击“下载报价单图片”后：

- 如果看到“保存到手机 / 分享”，直接点它
- 如果浏览器不支持，就点“打开图片后长按保存”
- 打开图片后，长按图片保存到相册
