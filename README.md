# 超能游学报价系统 V11.2.1 防丢保护 + 手机电脑同款导图版

## 基于版本

本版基于你回退后的稳定版 V11.2 修改。

## 本次只做两件事

### 1. 增加防丢功能

新增保护：

- 本地保存前自动生成本地历史备份
- 导入数据前后自动备份
- 恢复默认前自动备份
- 上传云端前自动备份
- 云端上传前自动生成云端历史备份
- 防止“1个学校/少量学校”误覆盖“多个学校”的云端数据

如果云端已有很多学校，而本地只有少量学校，上传云端会被阻止，并提示先从云端刷新。

后台新增：

系统设置 → 防丢备份中心

里面可以：

- 下载当前数据备份
- 查看本地历史备份
- 恢复本地历史备份
- 查看云端历史备份
- 恢复云端历史备份

### 2. 手机下载图片和电脑统一格式

手机端和电脑端现在都使用同一个 drawNativeQuoteCanvas 输出。

也就是：

- 同一套图片规格
- 同一套表格格式
- 同一套PNG
- 不再给手机端单独做另一种模板

电脑端会自动下载。
手机端会显示同款PNG预览，可点击“打开同款PNG长按保存”。

上传覆盖 GitHub 后，Vercel 重新 Redeploy。

## V11.2.7 修复
- 费用一表格中，课程行的“备注”不再显示课程课时。
- 课程行备注改为和房型一样，显示对应学习周数，例如：4周、8周、12周。


## V11.2.8 修复
- 修复超能折扣只按旺季覆盖周数计算的问题。
- 超能折扣现在按全部课程费 + 全部住宿费 + 旺季附加费计算。
- 示例：2300 + 1800 + 40 = 4140，95折优惠为 207 美元。


## V11.2.9 员工长期登录修复
- 员工登录后新增服务器长期记忆 Cookie，有效期一年。
- 手机切到后台、关闭标签页、重新打开或刷新时，会自动恢复员工登录。
- 即使手机浏览器暂时清掉 localStorage，也会通过服务器 Cookie 恢复原设备ID，避免误判为“已绑定其他手机”。
- 网络短暂断开或手机切后台时，不再清除员工登录状态。
- 主动点击“退出员工登录”时才会清除长期登录。


## V11.3.0 新增：圣诞元旦优惠
- 学校设置新增“圣诞元旦优惠”。
- 每个学校可单独开启/关闭，默认关闭，不影响没有该政策的学校。
- 可自定义优惠开始日期、结束日期。
- 可设置覆盖1周优惠、覆盖2周优惠、覆盖完整2周额外优惠。
- 自动报价页新增“圣诞元旦优惠”勾选项，学校后台开启且学习时间覆盖时自动勾选。
- 该优惠会进入费用一，并在报价单图片、计算明细和微信报价文案里显示。
