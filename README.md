# 超能游学报价系统 V10.4 长期优惠4周选项版

## 本次新增

长期优惠新增：

4周长期优惠

现在后台可以设置：

- 4周长期优惠
- 8周长期优惠
- 12周长期优惠
- 16周长期优惠
- 20周长期优惠
- 24周长期优惠

## 计算规则

系统会根据可享受长期优惠的周数自动匹配：

- 4-7周：用4周长期优惠
- 8-11周：用8周长期优惠
- 12-15周：用12周长期优惠
- 16-19周：用16周长期优惠
- 20-23周：用20周长期优惠
- 24周及以上：用24周长期优惠

## 与旺季外恢复优惠配合

如果开启：

旺季外时间自动恢复优惠

长期优惠也会按照旺季外可优惠周数重新匹配。

例如：

学生总共8周，但旺季外可优惠周数只有4周  
系统会使用4周长期优惠。

## 后台位置

学校数据库 → 学校设置 → 长期优惠
