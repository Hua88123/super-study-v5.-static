# 超能游学报价系统 V10.3 多课程宿舍周数可选修正版

## 本次真正修复

修复：

课程2周数 / 宿舍2周数选择后又自动变回 0 的问题。

## 问题原因

上一版虽然改成了下拉选择，但是系统有一个“防漏算周数”的自动补齐逻辑。

例如总周数 8 周：

课程1默认是 8 周  
你选择课程2 4 周  
系统发现 8 + 4 超过总周数 8  
旧逻辑会把课程2改回 0

所以你会感觉“选不了”。

## 现在修复后的逻辑

系统会记住你最后选择的是哪一个字段。

例如总周数 8 周：

课程1原来 8 周  
你选择课程2 4 周  

系统会自动变成：

课程1：4周  
课程2：4周

不会再把课程2改回0。

宿舍也是同样逻辑。

## 使用方式

自动报价页面：

多课程/多宿舍 → 开启

然后选择：

- 课程2周数
- 宿舍2周数

系统会自动调整课程1/宿舍1周数，保证总周数不超过学习周数，也不会漏算。
