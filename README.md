# 超能游学报价系统 V10.1 多课程多宿舍选项版

## 本次新增

自动报价页面新增：

多课程/多宿舍

默认是关闭，系统和以前一样：

- 1个课程
- 1个宿舍

如果开启，可以设置：

- 课程1周数
- 课程2
- 课程2周数
- 住宿1周数
- 宿舍2
- 宿舍2周数

## 使用场景

例如学生 8 周：

- 前 4 周 ESL
- 后 4 周 IELTS

或者：

- 前 4 周 三人间
- 后 4 周 单人间

系统会自动分段计算学费和住宿费。

## 防漏算规则

如果开启多课程/多宿舍后，2段周数不足总周数：

剩余周数会自动归到第1项。

例如总周数 8 周：

课程2填写 4 周，课程1空着  
系统自动算：

- 课程1：4周
- 课程2：4周

这样可以避免漏算费用。

## 报价单显示

网页报价单、复制微信报价、下载报价单图片都会显示：

- 课程1 / 课程2
- 宿舍1 / 宿舍2
- 各自周数和费用
