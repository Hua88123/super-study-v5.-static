# 超能游学报价系统 V11.8 手机端保存图片修正版

## 本次只修手机端保存，不改报价图模板

你确认现在报价图片可以，所以本版保持报价图模板不动，只修复：

- 手机端保存不了图片
- 微信 / iPhone / 安卓浏览器对 blob 下载不支持
- 手机点击下载没有反应

## 修复逻辑

手机端不再依赖 blob 下载，而是：

1. 直接把报价图转成 dataURL 图片显示在预览框里
2. 支持长按预览图保存
3. 支持“打开大图长按保存”
4. 支持系统分享/保存（浏览器支持时）
5. 支持复制图片（部分安卓 Chrome 支持）

## 手机端使用方式

点击“下载报价单图片”后：

优先：
长按下方预览图 → 保存图片

如果没有保存选项：
点击“打开大图长按保存” → 长按图片保存

如果浏览器支持：
点击“系统分享/保存”
