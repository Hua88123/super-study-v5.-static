# 超能游学报价系统 V10.8 稳定导图增强版

## 本次修复

你要求下载的报价图片和电脑端看到的报价单保持一致，本版继续加强：

1. 下载图片使用页面报价单本身导出，不再用另一套排版。
2. 导出时会复制一份电脑端报价单到离屏区域，再生成图片。
3. 手机端导出时也会强制使用电脑端宽版布局，避免手机窄屏导致图片变形。
4. 自动按报价单真实高度导出，课程多、优惠说明长时不会截断。
5. 课程区域新增“具体课程课时”，并单独显示报名周数。

## 页面报价单新增

### 具体课程课时

会显示：

- ESL 4周：1对1 4节 / 团课2节 / 选修课2节
- IELTS 4周：1对1 4节 / 团课4节 / 写作课1节

### 住宿安排

会显示：

- 三人间 4周
- 单人间 4周

## 学校优惠说明

学校优惠说明会自动换行显示，导出图片会按实际高度生成，不会只截取一小块。
