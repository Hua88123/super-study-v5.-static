# 超能游学报价系统 V11.2 手机电脑一致_宿舍押金修正版

## 本次修复

针对你反馈的两个问题：

1. 手机下载的图片和电脑端不一致
2. 宿舍押金 Dorm Deposit 被覆盖掉了

这版已修复。

## 修复内容

### 1）手机和电脑导出图片统一
现在手机端和电脑端导出使用同一套图片倍率和同一套导图布局逻辑。

这样导出来的报价图会更加一致，不会再出现：

- 手机一版
- 电脑一版

样式不一样的问题。

### 2）费用二区域改成按真实内容自动撑高
费用二表格底部的“合计”位置，改成跟着表格实际内容往下走。

这样最后几行项目，例如：

- Airport Pick-up
- Dorm Deposit

不会再被底部合计覆盖。

### 3）费用二项目仍然尽量保持单行
同时保留：

- 项目列更宽
- 项目列尽量单行显示
- 图片整体仍然是较小规格，适合手机保存
