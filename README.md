# 超能游学报价系统 V11 手机端原生导图水印修正版

## 本次重点修复

你反馈：

- 手机端还是下载图片失败
- 下载的图片没有全覆盖水印

这版已改成：

不再依赖 html2canvas / CDN / 网页截图组件，直接用浏览器原生 Canvas 生成报价图。

## 这样修复的好处

1. 手机端更稳定，不需要加载外部截图插件。
2. 不受手机浏览器截图限制影响。
3. 不容易因为网络、跨域、Logo 图片导致失败。
4. 水印由 Canvas 直接绘制，整张图全覆盖。
5. 水印会在底层和最后再盖一遍，避免导出后看不到。

## 图片内容保留

报价图仍然包含：

- 学校
- 入学/毕业时间
- 课程报名周数
- 具体课程课时
- 住宿安排
- 学校优惠说明
- 费用一
- 费用二
- 人民币总计
- 全覆盖水印

## 手机端使用方式

点击：

下载报价单图片

系统会弹出报价图预览。

手机端长按图片保存到相册。
