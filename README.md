# 超能游学报价系统 V10.9 手机端下载图片修正版

## 本次修复

修复手机端点击“下载报价单图片”失败的问题。

## 修复内容

1. 手机端导出时降低图片生成倍率，减少内存占用。
2. 下载图片不再强制自动下载，而是先弹出预览图。
3. 手机端可以长按预览图保存到相册。
4. Logo 会先转成图片数据，避免手机浏览器跨域导致截图失败。
5. 截图组件加载顺序优化，优先使用本地/稳定来源。
6. 失败提示更明确。

## 使用方式

手机端点击：

下载报价单图片

系统会弹出图片预览。

然后：

长按图片 → 保存到相册

## 本地截图组件状态

未内置本地 html2canvas，保留多 CDN 自动加载。
