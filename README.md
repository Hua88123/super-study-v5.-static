# 超能游学报价系统 V16 手机端真实PNG下载 + 数据修正版

## 这版修复两个问题

### 1. 手机端下载图片失败

V16 不再让手机端自己生成图片。

手机端点击“下载报价单图片”后，只把报价数据发给 Vercel API：

/api/quote-png

由服务器生成真实 PNG 图片返回给手机。

手机打开的是普通 image/png 图片，可以像普通网页图片一样长按保存。

### 2. 手机端学校数据丢失

这版增加了：

- 兼容旧 localStorage 数据
- 如果手机只剩默认学校，会自动尝试从云端拉取
- 保留原有 Supabase 云端同步

## 手机端使用方式

1. 手机点击“下载报价单图片”
2. 等待“正在生成手机PNG...”
3. 打开真实 PNG 报价图
4. 长按图片保存到相册

## 部署重点

这版新增：

api/quote-png.js

并新增依赖：

sharp

所以上传覆盖 GitHub 时，一定要包含：

- package.json
- api 文件夹
- script.js

上传后 Vercel 必须重新 Redeploy。
