# 超能游学报价系统 V11.2.1 防丢保护 + 手机电脑同款导图版

## 基于版本

本版基于你回退后的稳定版 V11.2 修改。

## 本次只做两件事

### 1. 增加防丢功能

新增保护：

- 本地保存前自动生成本地历史备份
- 导入数据前后自动备份
- 恢复默认前自动备份
- 上传云端前自动备份
- 云端上传前自动生成云端历史备份
- 防止“1个学校/少量学校”误覆盖“多个学校”的云端数据

如果云端已有很多学校，而本地只有少量学校，上传云端会被阻止，并提示先从云端刷新。

后台新增：

系统设置 → 防丢备份中心

里面可以：

- 下载当前数据备份
- 查看本地历史备份
- 恢复本地历史备份
- 查看云端历史备份
- 恢复云端历史备份

### 2. 手机下载图片和电脑统一格式

手机端和电脑端现在都使用同一个 drawNativeQuoteCanvas 输出。

也就是：

- 同一套图片规格
- 同一套表格格式
- 同一套PNG
- 不再给手机端单独做另一种模板

电脑端会自动下载。
手机端会显示同款PNG预览，可点击“打开同款PNG长按保存”。

## 部署方式

上传覆盖 GitHub 后，Vercel 重新 Redeploy。

不需要重新建表。
